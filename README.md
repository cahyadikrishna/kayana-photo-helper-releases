# Kayana Photo Helper — Downloads

Installers for Kayana Photo Helper.

**[Download the latest version](https://github.com/cahyadikrishna/kayana-photo-helper-releases/releases/latest)**

- **Windows:** download the `.exe` file and run it.
- **macOS:** download the `.dmg` file, open it, and drag the app into Applications.
  The first time, right-click the app → **Open** → **Open**.

Once installed, the app checks for new versions when it starts.
